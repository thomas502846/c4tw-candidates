## V11 重寫（v8）— 共生之家：服務「在地各種被機構排斥／隔離的人」

### 共生之家不是「失能長者居住」 — 是「在地各種被機構排斥的生命」

v6/v7 錯把共生之家窄化為「中重症長者照顧」。v8 從 5 個已知據點看：

| 據點 | 服務對象 |
|---|---|
| 文山共生之家 | 失能、原住民長者、**重度身障** |
| 南港共生之家 | **藥癮、愛滋病患**（弱勢族群） |
| 東勢共生之家 | 偏鄉部落需就醫長者（特殊洗腎個案） |
| 清流部落共生之家 | 失明 18 年、肌無力 |
| 知本共生之家 | 從青少年延伸到長者 |
| 共生社會住宅（林口） | 都市社宅居民／弱勢 |

→ **共生之家的核心不是「年齡或失能等級」，是「機構不要、不能、或不適合的生命，在社區重新被接住」**。

## 9. Challenge step v8

**Q1：v7 哪裡又錯了？**
- v6/v7 把文山共生之家 operator 寫成「銀享全球運營」 — 錯了兩輪
- v6/v7 沒抓到南港、清流（思德磊岸）、知本三個共生之家
- v6/v7 把共生之家服務對象窄化為「中重症長者」 — 漏掉藥癮 / 愛滋 / 身障 / 失明等

**Q2：v8 後骨架是否真正穩定了？**
- AIO 7 成員骨架（V10）穩定 — v6/v7/v8 沒改過
- 林依瑩 + 黃子華雙主角穩定
- V11 共生之家 — 從「鄰里123 旗下」（v5 錯） → 「跨組織 movement」（v6） → 「AIO 內+外多 operator」（v7） → 「服務多元被機構排斥群體」（v8） — **v8 把「為什麼這個 movement 重要」這個價值論述補上了，這應該是真正穩定**

**Q3：強懷疑者**
- 質疑：「『被機構排斥的生命』這個 framing 會不會太悲情？」 — 反駁：v8 用詞是「**機構不要、不能、或不適合**」，不全是排斥，也包括「機構式照顧不適合的多元需求」。實際對外文案可改為「**機構之外，還有家**」這類正向 framing。
- 質疑：「v6/v7 錯了兩輪，v8 自己也可能再錯。」 — 反駁：合理。但 v8 是基於**用戶提供的 2025 共生之家國際論壇分享文獻** — 這是同 source 中最權威的版本（論壇主辦自己說的）。比 Slack 碎片更可信。

**Q4：v9 觸發條件**
