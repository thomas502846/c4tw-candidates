## 1. 創照是誰（Nature）— v6 重新分層

**法律屬性**：股份有限公司，登記名稱 `創照服務設計股份有限公司`，社會企業（for-profit social enterprise）。

**業務屬性**：長照產業的中介層 — 培育跨專業人才、設計服務模式、開發數位基礎設施、把組合輸出給有現場的合作夥伴。

**v6 重要 reframing — 創照家族 vs 共生之家 movement 是兩件事，不要混淆**：

```
創照家族（CI 載體）        ≠         共生之家全台運動
直接擁有／經營：                     由創照家族 + 多個夥伴組織共同推動：
- 創照服務設計                       Direct operate（家族內）：
- CFT 照顧學校                       - 東勢共生之家（伯拉罕）
- Connect 10（v2 AI 層）             - 雙崎日照（伯拉罕）
- 伯拉罕（部落運營）                 Co-operate（家族 + 合作夥伴）：
- 鄰里123（協會）                    - 文山共生之家（銀享全球）
                                     - 清流226 部落共生之家（待確認）
                                     - …其他夥伴據點
                                     Reference / 學習源頭：
                                     - 卡桑の家（日本，市原美穗）
```

- **創照家族** = CI 主體 + 直接運營單位（5 ventures）
- **共生之家全台運動** = 創照家族「發起／整合」的、由多個組織各自運營的全國 movement
- 鄰里123 在 movement 中的角色：**整合對外品牌、推動募款、企業 ESG 對接、公益倡議** — 它聚合不同 operator 各自的據點故事，**不是 operator**

**家族識別事實**（v3-v5 unchanged 部分仍對）：
- 鄰里123 與 CFT 共用 414 台中市烏日區溪岸路 8-3 號 + 04-9252-6611
- 鄰里123 內政部字號 台內團字第1140116293號 + 衛部救字第1141362569號
- 伯拉罕登記在和平區東崎路一段育英巷17-5號

**創立邏輯**：（v5 unchanged）30 年弧線從 921／八八／部落生活重建 → 弘道 → 不老騎士 → 副市長 → 達觀部落／伯拉罕 → 創照／CFT → 鄰里123 + Connect 10。

> 「即使老去，即使生病，也想在熟悉的地方生活 — 打造願意接受失能與重症長者的社區」（2025 Co-Living Care 國際論壇主標）
>
> 文山共生之家（銀享運營）FB about：「文山共生之家不僅是一個居住空間，更是我們對於『在地安老』最深情的承諾。延續日本『共生（Kyosei）』的精神…**在這裡，我們不談『患者』，只談『生活』**」

**居住設計三原則**（從 Summit 簡報抽取，跨據點通用）：
1. 5～6 人尺度的群體生活
2. 休憩 / 停留 / 療癒空間區分

### 黃子華 角色（v6 重新發現的關鍵 figure）
**三位一體獨立專業者**：
- **雲林好所宅 owner**（居家醫療 + 長照機構，自己的事業體）— **不是創照家族內部單位**，是獨立合作組織

**對 c4twweb 的意涵**：
- 黃子華應該有獨立的個人 page（建議 `/about/co-founder`），平等於林依瑩 page，不是子段落

## 9. Challenge step v6（誠實復盤 v5 的 over-confidence）

**Q1：v5 哪裡錯了？**
- v5 的「共生之家 5 處」清單把不同組織各自運營的據點都歸到鄰里123 名下 — over-claim ownership

- v5 Challenge 結尾說「v6 不必發生 — 補洞只會 refine 細節，不會推翻骨架」 — **這個自信是錯的**。骨架（共生之家 ownership 範圍）就是被推翻了

**Q2：v6 還欠什麼？**
- 銀享全球 / 楊寧茵 的具體角色 + 與文山共生之家的關係深度 — 沒實際抓
- 清流 226 的 operator 確認 — 不知道是誰運營
- 「其他夥伴據點」的完整名單
- 黃子華的個人聲音／背景／公開資料 — 仍未深挖
- 雲林好所宅 的具體業務範圍與規模

**Q3：v6 的骨架是否更穩定？**
比 v5 穩定 — 因為：
- 「家族 vs movement」分離後，後續加任何據點 / operator 不需要再改骨架
- 「林依瑩 vs 黃子華」雙主角後，後續加任何共創／夥伴角色不需要再改骨架

**Q4：強懷疑者怎麼挑？**

**Q5：v7 觸發條件**

但 v7 不太可能 推翻 v6 骨架 — v6 的兩個分離（家族 vs movement、林依瑩 vs 黃子華）已經夠 robust 容納未來補充。
