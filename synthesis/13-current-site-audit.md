## 0. 技術 stack（拍版）
- **WordPress** + **Elementor**（從 `wp-content/uploads/elementor/thumbs/` 圖檔路徑判定）
- 字體：**Inter sans-serif**
- 背景：純白 `rgb(255,255,255)`
- 中文字體未強制，靠 Inter fallback 到系統中文（Mac SF / Windows Microsoft JhengHei）
- Hosting：戰國策 Plesk WP（已知）
- Enrich-based redesign 的後台改寫成本：低（WP 直接編輯 / Elementor 拖拉）；遷移 AWS 時建議**靜態匯出**或用 Next.js / Astro 重做
